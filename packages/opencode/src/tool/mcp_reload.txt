Reload all MCP servers from the opencode.json configuration. This re-reads the MCP configuration, reconnects changed or disconnected servers, and drops removed ones. For a remote server that declares a `restart` command, the command is run (and awaited) before reconnecting, so the external process is effectively restarted instead of merely reconnected. Use this after modifying opencode.json to apply changes without restarting the daemon. Requires user confirmation.
