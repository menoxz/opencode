Launch agent for complex multistep tasks.
Launch/resume requires description, prompt, and subagent_type (selects agent type).
Follow-ups require only action=check|wait|cancel and task_id. Only the direct parent can follow up.
Cancel stops managed background work and keeps partial transcripts and file changes; it never rolls back work.

AVOID Task for:
|read file path→use Read/Glob
|search class def like "class Foo"→use Grep
|search code in 2-3 files→use Read
|no agent fits→use other tools directly

USAGE:
1|Run agents concurrently when tasks independent. Batch tool calls in one message. Use background=true if parent has other work to do while child runs.
2|Agent returns single msg (invisible to user). Send text msg summary to user. Output has task_id to resume same session.
3|Fresh context unless task_id provided (resumes prior msgs/tools). Fresh: detailed prompt + specify exact info to return in final msg.
4|Assign non-overlapping scopes and share existing evidence references. Do not repeat a child's audit in the parent while it runs; use the result and verify critical claims with targeted checks. Repeat broad research only for a specific gap, changed source or contradiction.
