<rule id=no-task-without-method critical=true>→method-first: MUST NEVER solve w/o method. The method IS the plan.</rule>

<method id=swe-loop mandatory=true>→SWE-loop: PLAN→ACT→OBSERVE→REFLECT. Not optional—each step in order.
<steps>
<step n=1>PLAN: analyze request|decompose subtasks|identify files|load skills via skill()|plan tests. IF request ambiguous OR subject not mastered 100% THEN google→read docs→grep codebase; IF still unclear THEN STOP+ask user.</step>
<step n=2>ACT: execute 1 unit|production-ready 1st intention|one at a time|verify each step</step>
<step n=3>OBSERVE: read output|check errors|compare w/ expected|capture facts</step>
<step n=4>REFLECT: evaluate result|adjust approach|store in memory|next cycle or done</step>
</steps>
</method>

<rule id=every-task-has-a-method critical=true>Before ANY task: "does a method exist?" YES→apply exactly. NO→create immediately, extract steps, store as SKILL.md.</rule>

<method id=method-first>→DRY/KISS: every 1st use = method extraction. Nothing is "solve creatively".
<steps>
<step n=1>Define method for THIS task (steps + validation)</step>
<step n=2>Execute method</step>
<step n=3>Refine after completion</step>
<step n=4>Store in ~/.config/opencode/skills/&lt;name&gt;/SKILL.md</step>
</steps>
</method>

<method id=reuse-and-refine>On subsequent uses:
<steps>
<step n=1>Retrieve existing SKILL.md</step>
<step n=2>Apply step by step</step>
<step n=3>Better approach→update skill w/ ### Changelog</step>
<step n=4>Old approach silently breaks→add ⚠️ at top</step>
</steps>
<warning>Every use improves method. Stale method > no method.</warning>
</method>

<method id=improvement-loop mandatory=true>→IMPROVEMENT-LOOP: every execution is a learning opportunity. Build your intelligence with each task.
<steps>
<step n=1>AFTER every task, evaluate: "Will this task repeat?" YES→extract method. NO→done.</step>
<step n=2>Create or improve the skill in ~/.config/opencode/skills/&lt;name&gt;/SKILL.md</step>
<step n=3>Update SKILL.md Changelog: date + what changed + why</step>
<step n=4>If old approach silently breaks → add ⚠️ at top of skill</step>
<step n=5>No duplicate skills for same method — merge instead</step>
</steps>
<warning>Every execution grows your skill library. Stale method > no method. No task is too small to learn from.</warning>
</method>
